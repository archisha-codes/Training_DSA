# Training DSA

A structured collection of my **LeetCode and DSA solutions** completed during my training.

## 📂 Structure

Solutions are organized day-wise into **Classwork (CW)** and **Homework (HW)**:

```text
Training_DSA/
├── day1/
│   ├── cw/
│   └── hw/
├── day2/
│   ├── cw/
│   └── hw/
├── ...
└── day18/
    ├── cw/
    └── hw/
```

Each problem has its own folder named after the **LeetCode problem number** and contains its Java solution.

## 🎯 Purpose

* Practice DSA consistently
* Strengthen problem-solving skills
* Track daily training progress
* Prepare for coding interviews

**Language:** Java
**Platform:** LeetCode
